코토다망 최장 단어 탐색기 v1.25.1
====================================

실행
----
1. ZIP 전체를 원하는 폴더에 압축 해제합니다.
2. KotodamanWordFinder.exe를 실행합니다.
3. 프로그램 폴더의 Data 폴더는 삭제하거나 따로 옮기지 마세요.
   기본 단어 사전과 기본 캐릭터 이미지가 들어 있습니다.

업데이트
--------
- 새 버전 ZIP은 새 폴더에 압축 해제해 실행해도 됩니다.
- 캐릭터 수정 내용, 덱, 프리셋, 학습 자료와 설정은 자동으로 유지됩니다.
- 새 버전에 추가된 캐릭터는 기존 사용자 수정값을 건드리지 않고 자동으로 병합됩니다.

사용자 데이터
-------------
- 프로그램 상단의 '사용자 데이터' 버튼을 누르면 실제 저장 폴더가 열립니다.
- 저장 위치: %LocalAppData%\KotodamanWordFinder\Data
- 백업 파일: %LocalAppData%\KotodamanWordFinder\Backups

오류가 발생했을 때
------------------
1. 프로그램 상단의 '오류 로그' 버튼을 누릅니다.
2. 가장 최근 날짜의 log 파일을 확인합니다.
3. 오류 문의 시 해당 log 파일과 발생 직전의 작업을 함께 전달해 주세요.


[데이터 업데이트 ZIP 적용]
1. 프로그램을 종료합니다.
2. 받은 데이터 업데이트 ZIP을 apply_data_update.bat 위에 끌어다 놓습니다.
3. 적용 전 자동 백업 후 캐릭터·이미지만 병합됩니다.
4. 사용자가 직접 수정한 값과 충돌하면 사용자 값을 보존합니다.
