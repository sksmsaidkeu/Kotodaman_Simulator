Kotodaman Word Finder v1.24.2 → v1.25.0 패치
================================================

1. 실행 중인 프로그램을 완전히 종료합니다.
2. 이 패치 ZIP의 내용을 기존 v1.24.2 프로젝트 폴더에 그대로 압축 해제합니다.
3. 같은 이름의 파일은 모두 덮어씁니다.
4. clean_run.bat을 실행해 기존 bin/obj를 지우고 다시 빌드합니다.
5. 정상 실행을 확인한 뒤 정식 배포본이 필요하면 publish_release.bat을 실행합니다.

v1.25.0 첫 실행 시
------------------
- 기존 캐릭터/덱/프리셋/학습 자료가 %LocalAppData%\KotodamanWordFinder\Data로 자동 이전됩니다.
- 기존 프로그램 폴더의 Data는 기본 사전과 기본 이미지로 계속 사용하므로 삭제하면 안 됩니다.
- 실제 수정 데이터는 메인 화면의 '사용자 데이터' 버튼으로 열 수 있습니다.

주의
----
- 이 패치는 v1.24.2 기준입니다.
- 사용자 데이터 이전 후에는 프로그램 폴더의 characters.json을 직접 수정하지 말고 앱에서 수정하세요.
- 배포할 때 publish_release.bat이 최신 사용자 캐릭터/이미지를 자동으로 배포용 Data에 반영합니다.
