# Kotodaman Word Finder v1.25.1
제작자: 김정석(프로그램 메인 담당), 박진수(최적화 및 기능 개선/베포 담당)

## v1.25.1 변경 사항

- UI 배치 변경 없이 프로그램 업데이트와 캐릭터 데이터 업데이트를 분리하는 기반을 추가했습니다.
- 프로그램 버전과 데이터 버전을 별도로 관리합니다.
  - 프로그램 버전: `1.25.1`
  - 초기 데이터 기준 버전: `2026.08.19.1`
- `create_data_update.bat`으로 이전 공식 기준 이후 달라진 캐릭터와 이미지만 데이터 업데이트 ZIP으로 만들 수 있습니다.
- 데이터 업데이트는 캐릭터 추가·수정·삭제와 이미지 변경을 비교합니다.
- `apply_data_update.bat`에 업데이트 ZIP을 끌어다 놓으면 적용 전 사용자 데이터 전체를 자동 백업한 뒤 병합합니다.
- 기존 사용자가 수정한 필드와 공식 업데이트가 충돌하면 3-way merge로 사용자 값을 보존합니다.
- 공식 데이터에서 삭제된 캐릭터라도 사용자가 수정한 상태라면 자동 삭제하지 않습니다.
- 데이터 업데이트 적용 로직을 `DataUpdateService`로 분리해 이후 UI의 `업데이트 확인/적용` 버튼에서도 그대로 사용할 수 있게 했습니다.
- `accept_data_baseline.bat`으로 실제 배포가 끝난 데이터 버전만 다음 비교 기준으로 확정하고, 해당 패치를 향후 전체 배포본의 자동 적용 체인에 포함합니다.
- `publish_release.bat`은 승인된 데이터 기준과 현재 `Data`가 같은지 먼저 검사하고, 프로젝트 버전을 자동으로 읽어 배포합니다. ZIP 생성 후 중복된 압축 전 Publish 폴더와 `bin/obj`를 자동 삭제합니다.
- `clean_workspace.bat`으로 개발 중 생성된 `bin`, `obj`, Publish의 압축 해제 폴더를 정리할 수 있습니다. 기존 portable ZIP은 보존합니다.

## v1.25.0 변경 사항

- 프로그램 기본 데이터와 사용자 수정 데이터를 분리했습니다.
  - 기본 사전·기본 캐릭터 이미지: 프로그램 폴더의 `Data`에서 읽기 전용으로 사용
  - 캐릭터 편집·덱·프리셋·GACCAG·스크린샷 학습 자료: `%LocalAppData%\KotodamanWordFinder\Data`에 저장
- 첫 실행 시 기존 Data의 사용자 자료를 자동 이전합니다. 기본 이미지 143MB는 복사하지 않고 공용으로 읽어 저장 공간이 이중으로 늘지 않습니다.
- 새 버전에 새로운 캐릭터 ID가 포함되면 기존 사용자 수정값은 유지하면서 새 캐릭터만 자동 병합합니다.
- 백업·복원 파일은 `%LocalAppData%\KotodamanWordFinder\Backups`에 저장합니다.
- 처리되지 않은 오류와 비동기 오류를 `%LocalAppData%\KotodamanWordFinder\Logs`에 기록합니다.
- 메인 화면에 `사용자 데이터`, `오류 로그` 폴더 열기 버튼을 추가했습니다.
- 프로젝트·파일·어셈블리 버전을 1.25.0으로 통일했습니다.
- Windows 실행 파일과 작업 표시줄에 표시되는 전용 앱 아이콘을 추가했습니다.
- `publish_release.bat`을 추가했습니다. .NET 8 SDK가 설치된 개발 PC에서 실행하면 Windows x64 자체 포함 포터블 ZIP을 자동 생성합니다.
- Release 배포 시 `bin`, `obj`, 백업·임시 파일과 사용하지 않는 OpenCV x86/FFmpeg 파일을 제외하도록 게시 설정을 추가했습니다.
- 실제 파일이 없던 모드시프트 이미지 참조 1건을 정리해 기본 이미지로 안전하게 대체되도록 했습니다.


## v1.24.2 변경 사항

- GameWith 전 캐릭터 연속 가져오기에서 일부 항목 처리 중 무한 대기처럼 보이던 현상을 수정했습니다.
- A 평가 후보는 GameWith에서 6성이 확인되면 코토다망DB 자동 검색을 생략합니다.
- GameWith에서 레어리티가 비어 있는 A 후보만 코토다망DB 보강을 최대 10초 동안 시도합니다.
- 캐릭터 하나의 페이지 분석은 최대 28초로 제한하고, 초과 시 해당 항목만 평가표 정보로 복구한 뒤 다음 캐릭터를 계속 처리합니다.
- GameWith 요청은 18초, 코토다망DB 요청은 7초, 이미지 다운로드는 15초 제한을 적용했습니다.
- 중지 버튼의 취소 신호가 DB 보강 단계에서도 정상 전파되도록 수정했습니다.
- 진행 문구에 `항목당 최대 28초`를 표시해 느린 항목과 전체 멈춤을 구분할 수 있게 했습니다.

## v1.23.8 변경 사항

- `캐릭터 웹 반자동 등록`의 연속 등록 영역에 **GameWith 전 캐릭터 조건 검색**을 추가했습니다.
- GameWith 전 캐릭터 평가표에서 `SSS / SS / S`를 선택하고, `서브 또는 리더 중 하나 / 서브만 / 리더만 / 서브·리더 모두` 기준으로 링크를 추릴 수 있습니다.
- `오리지널만`을 선택하면 목록 행의 콜라보 메타데이터를 먼저 제외하고, 연속 가져오기 중 개별 캐릭터 페이지에서도 콜라보 여부를 다시 확인합니다. 판별이 애매한 항목은 자동 삭제하지 않고 검수 메모를 남깁니다.
- `이미 등록된 이름 제외`를 지원하며, 조건 검색으로 찾은 캐릭터는 기본 분류가 `오리지널`로 설정됩니다.
- 등록 전 검수표에 GameWith의 `서브 / 리더 평가` 열을 추가했습니다.

## v1.23.7 변경 사항

- 세로형 코토다망 덱 스크린샷의 자동 4×3 영역을 실제 문자 원 간격 기준으로 다시 보정했습니다.
  - 열/행이 뒤로 갈수록 슬롯 중심이 밀리던 기존 기본 영역을 줄여, 일러 ORB와 문자 원 색상 판정이 같은 카드 위치를 보도록 맞췄습니다.
- 덱 스크린샷 인식에 `속성색 보조 판정`을 추가했습니다.
  - 게임 덱 카드의 문자 원/테두리 색을 읽어 캐릭터 DB의 속성과 함께 후보 순서를 보정합니다.
  - 색 판정이 틀려도 기존 ORB 상위 후보 220개는 그대로 보존하고, 감지 속성 후보를 추가로 구제하므로 하드 필터보다 안전합니다.
- 기존 `검수 결과 학습` 샘플을 속성색 학습에도 재사용합니다.
  - 확정된 슬롯 이미지와 캐릭터 속성을 이용해 실제 게임 UI의 속성별 색 분포를 자동 학습합니다.
  - 火/水/木/光/闇뿐 아니라 학습 샘플이 쌓이면 天/冥/虹도 데이터 기반으로 판정합니다.
  - 속성이 바뀔 수 있는 듀얼/동일명 모드시프트 샘플은 속성색 학습에서 제외해 오염을 줄였습니다.
- 학습 데이터가 부족하면 문자 원을 직접 찾아 火/水/木/光/闇 기본 5속성만 보수적으로 색 판정합니다. 확신이 낮으면 속성 보정을 적용하지 않습니다.
  - 기본 HSV 판정은 天/冥/虹을 다른 색으로 오인할 수 있어 후보 불일치 감점은 하지 않고, 일치 후보에만 작은 가산점을 줍니다.
  - 기본 판정은 55% 미만이면 버리고, 신뢰도도 최대 68%로 제한해 색상만으로 자동 확정되지 않게 했습니다.
  - 기본 색상 가산점은 1점 미만으로 제한해 ORB 점수 차이가 있는 정답을 뒤집기보다 동점/초근접 후보 정리에만 쓰도록 했습니다.
- 검수 화면에서 후보명 앞에 `[속성]`을 표시하고, `속성색 闇 82% (학습 3장)` 같은 힌트를 표시합니다.
- 속성색이 매우 확실하고 1위 후보만 속성이 맞는 경우 자동 확정 기준을 소폭 보조합니다.

## v1.23.6 변경 사항

- 캐릭터 일괄 수정 표의 `등급 / 속성 / 종족`을 드롭다운 대신 직접 입력 가능한 텍스트 칸으로 변경했습니다.
  - 셀을 클릭해 바로 타이핑/붙여넣기 가능
  - 속성은 `火 水 木 光 闇 天 冥 虹`, 종족은 `神 魔 英 龍 獣 霊 物 妖` 입력 지원
  - 한국어 `화/수/목/광/암/천/명`, `신/마/영웅/용/짐승/령/물/요괴`도 저장 시 내부 표기로 정규화
  - 잘못된 값은 `변경 내용 적용` 시 캐릭터 이름과 함께 오류로 알려 데이터가 조용히 다른 값으로 바뀌지 않게 했습니다.
- 체크 항목 일괄 변경의 등급/속성/종족도 텍스트 입력으로 변경했습니다. 빈칸은 유지, 속성/종족에 `미입력`을 넣으면 값을 지웁니다.
- 일괄 수정 목록에 42px 캐릭터 일러 썸네일을 추가했습니다. 화면에 보이는 행부터 비동기로 불러와 1,400명 이상에서도 초기 로딩을 막지 않도록 했습니다.
- 기존 v1.23.5의 GameWith nullable 경고 수정과 상세 편집 선택 강조는 그대로 유지합니다.
